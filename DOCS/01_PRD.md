# 카페 운영 기록·수익성 확인 프로그램 PRD

- 문서 상태: 검토용 초안 — 수업 중·수업 후 범위 제안의 사용자 확인 대기
- 기준 자료: `C:\CAFE\E\매장운영데이터.xlsx`, `매장운영데이터.json`, `데이터설명.md`
- 실습 시간: 기획·화면 설계·개발·검사·배포를 포함한 총 4시간

## 사용 목적

카페의 판매·비용·재고 기록을 관리하고, 메뉴별 수익성과 기간별 실적 및 손익을 확인한다. 재료의 잔량과 부족 가능성을 확인해 운영 판단에 참고한다. 기록을 직접 입력·수정·삭제하고, 엑셀 양식을 이용한 기록 가져오기와 데이터 저장·백업·복원을 지원한다.

이 문서는 제품이 제공할 기능과 완료 기준을 정한다. 계산식, 화면 배치, 구현 기술, 세부 조작 절차는 정하지 않는다. 수업 범위는 4시간 안에 핵심 흐름을 완성할 수 있도록 나눈 **제안**이며 아직 승인되지 않았다.

## 자료의 종류·기간·단위·중복 주의사항

첨부 엑셀과 JSON은 같은 가상 매장 ‘프렙 카페’ 데이터의 두 형식이다. 엑셀은 첫 행이 열 이름이고, 데이터 설명에 따르면 두 형식을 모두 가져오지 않고 하나만 사용해야 한다.

| 자료 | 건수 | 내용 |
|---|---:|---|
| 공급사 | 3 | 공급사 ID와 이름 |
| 재료 | 11 | 기준 단위, 구매 용량·가격, 납기·안전 재고 일수 |
| 메뉴 | 8 | 메뉴, 판매 기준가, 분류, 레시피 버전 |
| 레시피 | 22 | 메뉴 1개당 재료 사용량, 적용 채널 |
| 재료 가격 이력 | 33 | 날짜별 구매 가격과 구매 용량 |
| 영업 달력 | 457 | 영업 여부, 마감 여부, 날씨, 메모 |
| 판매 기록 | 6,112 | 날짜·메뉴·채널별 판매 수량과 당시 금액·비용 정보 |
| 초기 재고 | 11 | 첫 영업일 시작 전 재료 수량 |
| 재고 기록 | 1,515 | 입고·폐기·실사 조정 |
| 월 비용 계획 | 120 | 월별 비용 항목과 계획 금액 |
| 비용 기록 | 3,560 | 날짜별 비용 항목과 금액 |

- 기록 기간은 2025-07-01~2026-09-18이다. 달력은 2026-09-30까지 있으나 9월 19일 이후 판매·비용 기록은 자료에 없다. 미래의 미마감일은 판매 0건으로 간주하지 않는다.
- 금액은 원화(KRW)이며 부가세 제외다. 재료 기준 단위는 g·ml·개이고, 판매 수량은 메뉴별 수량이다.
- 판매 자료는 주문별 내역이 아닌 날짜·메뉴·채널별 집계다. 제공 파일에서는 판매 ID 중복과 같은 날짜·메뉴·채널 조합 중복이 확인되지 않았다. 새 입력·가져오기의 중복 처리 기준은 미정이다.
- 월 비용 계획과 날짜별 비용 기록은 같은 비용을 월·일 기준으로 표현한 것이므로 서로 더해 별도 지출로 계산하면 안 된다.
- 구매 가격은 구매 용량 전체의 금액이고, 레시피 사용량은 메뉴 1개 기준이다. 포장 재료는 포장 판매에만 적용되는 경우가 있다.
- 재고 증감에서 입고는 양수, 폐기는 음수다. 실사 조정에는 양수·음수 및 실제 측정 수량이 있다. 일부 재고 기록의 단가·공급사는 빈칸이며, 빈칸은 0과 다르다.
- 기존 판매 기록의 단가·할인·매출·수수료·원가 값은 과거 시점의 기록이다. 이를 미래 기록의 계산 기준으로 그대로 적용할지는 미정이다.
- 자료는 직접 구성한 가상 샘플이며 실제 매장의 확정 운영 규칙이 아니다. 비용 배분, 전망 방법, 재고 처리 정책은 자료에서 정하지 않는다. JSON의 `settings`도 비어 있다.

## 사용자와 사용 순서

- 주 사용자: 매장의 운영 기록을 입력하고 실적을 확인할 담당자. 구체적인 사용자 역할·공동 사용 여부는 미정이다.
- 사용 순서: 매장 메뉴·재료·레시피 등 기준 정보를 확인하고, 판매·비용·재고 변동을 기록한 뒤, 기간별 메뉴 수익성·손익·재료 잔량을 확인한다. 엑셀 가져오기, 예상 손익, 발주 참고, 백업·복원은 합의된 범위에 따라 추가한다.
- 이번 실습의 핵심 흐름 제안: **판매 기록 입력 → 메뉴 수익성 확인 → 손익과 재료 잔량 확인**.

## 필수 기능

### 수업 중 구현 제안 — 승인 대기

- 판매 기록과 비용 기록을 직접 입력·수정·삭제한다.
- 메뉴별 수익성을 확인한다.
- 일·월 기준 실제 실적과 손익을 확인한다.
- 재료 입고·폐기·실제 재고를 기록하고 재료 잔량을 확인한다.
- 입력된 데이터가 저장되고 다시 조회된다.
- 누락되거나 사용할 수 없는 입력을 알아볼 수 있고, 오류가 생겨도 잘못된 기록이나 결과가 정상 처리된 것처럼 보이지 않는다.
- 기존 데이터의 메뉴·재료·레시피 등 기준 정보를 이용한다. 수업 중 기준 정보 편집까지 포함할지는 미정이다.

### 수업 후 확장 제안 — 승인 대기

- 판매·비용 기록용 엑셀 양식 내려받기와 엑셀 기록 가져오기.
- 예상 손익 확인.
- 주·분기·반기·연간 조회. 수업 중 제안 범위는 일·월 조회다.
- 재고와 사용량을 참고한 필요 발주량 표시.
- 데이터 백업과 복원. 수업 중에는 기록 저장을 제안한다.

## 제외 기능

아래 항목은 위 수업 중 MVP 제안에 포함하지 않는다. 제품의 향후 범위로 포함할지는 별도 합의가 필요하다.

- 수업 후 확장으로 분류한 엑셀 가져오기·양식 내려받기, 예상 손익, 주·분기·반기·연간 조회, 발주량 참고, 백업·복원.
- POS(판매 시점 정보 시스템)나 결제 서비스에서 판매 내역을 자동으로 받아오는 기능.
- 공급사에 발주서를 보내거나 결제를 실행하는 자동 주문 기능.
- 세무 신고·회계 장부 작성 기능.

## 완료 기준

다음은 수업 중 MVP 제안이 승인될 경우 적용할 완료 기준이다. 세부 계산 기준은 별도 합의 전까지 확정하지 않는다.

- 판매·비용을 입력·수정·삭제한 결과가 선택한 기간의 조회에 반영되고, 삭제한 기록은 결과에 계속 포함되지 않는다.
- 메뉴별 수익성과 일·월 실제 손익이 포함 범위 안의 기록을 빠짐없이 반영하며, 같은 기록이 중복 반영되지 않는다.
- 재료 잔량이 합의한 입고·폐기·실제 재고 처리 정책에 따라 표시된다.
- 필수 입력이 비었거나 값이 잘못된 경우 이를 알아볼 수 있고, 잘못된 입력으로 기록이나 집계가 왜곡되지 않는다. 빈칸과 숫자 0은 구분된다.
- 저장한 기록이 다시 열어 확인할 때 유지된다.
- 구현하기로 합의한 기능은 대표적인 정상 입력, 수정·삭제, 빈칸·0, 기간 경계, 중복 입력 사례에서 계산과 저장 결과가 검증된다.
- 수업 중 MVP가 수업에서 합의한 배포 위치에서 열리고, 핵심 흐름을 따라 결과를 확인할 수 있다.
