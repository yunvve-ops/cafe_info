## 자료·환경 및 제한

- 엑셀과 JSON은 같은 매장 자료의 대체 형식이다. 초기 자료에는 엑셀 한 형식만 썼다. 엑셀의 레시피 적용채널(포장 8행)이 JSON 복사본에는 빠져 있어, 채널별 원가 계산이 가능한 엑셀을 선택했다.
- 샘플은 가상 매장, 원화·부가세 제외, 자료 기간 2025-07-01~2026-09-18이다. 자료에 없는 날을 매출 0으로 채우지 않았다.
- 앱은 로컬 PGlite 저장소로 실행한다. Supabase 운영 DB 접속, 인증/접근 제어, Vercel 배포는 검사하지 않았으며 배포하지 않았다.
- 판매 집계 수정·삭제, 비용, 재고, 손익은 개발 계획의 EPIC 2·3 또는 범위 결정이 필요한 부분이지만 현재 코드는 제공하지 않는다. 이를 정상 기능으로 간주하지 않았다.
- 엑셀 가져오기·양식, 예상 손익, 발주 참고, 백업·복원은 PRD·FRD상 수업 후 확장이라 현재 개발 계획의 EPIC 밖이다. 사용자가 이번 요청에서 파일 처리 검사를 언급했으나 구현이 없어 전부 미확인으로 기록했다.
